# Description
This program opens an OpenGL window and shows a single rectangle with smooth animation. The rectangle slowly changes its color from red to white while also scaling (getting bigger and smaller) and rotating along both the X and Y axes.The animation runs continuously and is time-based, so everything moves and changes automatically without any user input.

# Language & Tools
 - C++
 - OpenGL (GLFW + GLAD)
 - VS Code
 - Windows OS

# How to Compile and Run
 1. Open the project folder in terminal
 2. Compile the source file (main.cpp) using your OpenGL setup
 3. Run the generated executable file
 4. The OpenGL window will open and start the animation
 
# Key Functionality
1. Rectangle Animation
 - Starts with a red color
 - Smoothly changes from red to white over time
 - The color transition is continuous and automatic
2. Movement and Effects
 - Scaling: The rectangle slowly grows and shrinks
 - Rotation: It rotates around both:
    a.X-axis
    b.Y-axis
 - These effects together create a simple 3D-like motion
3. Window Setup
 - Window title: Animated Rectangle - OpenGL
 - Displays only one animated rectangle
 - Runs in a continuous loop until the window is closed
